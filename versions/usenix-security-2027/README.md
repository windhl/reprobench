# USENIX Security 2027

此目录是新投稿版本的独立工作区。目前只包含原有模板压缩包、保存的征稿网页，以及从压缩包原样提取的官方 LaTeX 示例。

`paper/usenixsecurity2027.tex` 是格式示例，不是 ReproBench 稿件。尚未从 AAAI 或 arXiv 迁入研究正文，也没有新增实验结果。

从仓库根目录运行 `bash compile.sh usenix-security-2027` 可尝试构建示例。本机缺少其要求的 `plainurl.bst`，目前会在 BibTeX 阶段明确报错；原始模板未作修改。

后续正文放 `paper/`，实验配置和结果放 `experiments/`，修改计划放 `notes/`，实际投稿文件放 `submission/`。
