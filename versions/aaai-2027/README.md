# AAAI 2027

`paper/main.tex` 是整理前 `reprobench.tex` 的原样副本；正文、参考文献和插图独立保存。`paper/appendix_standalone.tex` 和 `paper/ReproducibilityChecklist.tex` 分别为独立附录与复现清单。

正文来源是当前工作区，包含整理前未提交修改，尚未与实际投稿记录逐项核对。原有 PDF 和审稿意见保存在 `submission/`，不会由构建脚本覆盖。

在仓库根目录执行 `bash compile.sh aaai-2027`，输出位于 `build/aaai-2027/`。

实验快照见 [experiments/README.md](experiments/README.md)，来源记录见 [manifest.json](manifest.json)。
